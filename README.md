# Responsive Webpage Project

This is a simple responsive webpage with a fixed navbar, collapsible left menu, and a right panel. The page adapts to various screen sizes using CSS media queries, and includes a JavaScript function to adjust the page's width based on the screen size.

## Features

- **Fixed Navbar**: A fixed top navbar that does not move when scrolling.
- **Responsive Layout**: The layout adjusts to different screen sizes:
  - Shrinks page width by 90% for screens between 992px and 1600px.
  - Shrinks page width by 80% for screens between 700px and 767px.
  - Shrinks page width by 75% for screens between 600px and 700px.
  - Shrinks page width by 50% for screens less than or equal to 600px.
- **Collapsible Left Menu**: A left-side menu with navigation links (Dashboard, Profile, Settings, Help).
- **Right Panel**: Displays notifications and quick links.
- **Footer**: A footer at the bottom of the page with a copyright message.

## Technologies Used

- **HTML**: Structure of the webpage.
- **CSS**: Styling and layout (including responsive design using media queries).
- **JavaScript**: Functionality for adjusting the page width based on screen size.

## Project Structure

- `index.html`: Contains the main structure and content of the webpage.
- `styles.css`: Contains the styling rules, including responsive design.
- `script.js`: Contains JavaScript for adjusting page width based on screen size.
